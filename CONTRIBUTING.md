# Contributing

This is one of Mario's personal Quill repositories. Follow the
[Quill solo Git workflow](https://github.com/marioisbeck/quillServer/blob/main/setup/git-workflow.md).

Work directly on `main`: edit, check, commit and push. An implementation request
authorizes scoped delivery unless Mario limits it. PRs and branches are optional
for collaboration or isolation. Keep security hooks, relevant checks and
repository-specific instructions in AGENTS.md. Preserve unrelated and in-flight
work. Company repositories keep their own policy.
