# Contributing

This is one of Mario's four Quill repositories. Follow the
[canonical Quill Git workflow](https://github.com/marioisbeck/quillServer/blob/main/setup/git-workflow.md)
and its [delivery procedure](https://github.com/marioisbeck/quillServer/blob/main/config/workspace/skills/gitflow-commits/SKILL.md).

Work on the personal `mario` workbench. Independent topics become PRs into
`main`; Mario merges with a merge commit. `develop` is legacy migration state.
Do not fork the policy here. Preserve repository-specific security and
application validation requirements in AGENTS.md.
